# OpenCode 键盘状态灯

你在 OpenCode 里跑着几个会话，人已经切去干别的了。这个程序让**键盘上的数字键替你盯着**：
哪个会话停下来等你，对应那个键就亮起来；跑完了亮一下绿；失败了亮红。

它同时会在托盘放一个小图标，并弹气泡通知。

没有键盘也能用——键盘只是加分项。

## 你会看到什么

| 会话状态 | 键盘 | 托盘 | 亮多久 |
|---|---|---|---|
| 正在跑 | **不亮** | 紫 | — |
| 停下来问你（权限/提问） | 黄，一明一暗呼吸 | 黄，闪 | 一直到你处理，最长 10 分钟 |
| 跑失败了 | 红 | 红 | 5 分钟 |
| 跑完了 | 绿 | 绿 | 1 分钟 |
| 没有会话 | 全黑 | 灰 | — |

键位就是编号：第 1 个会话在键 `1`，第 5 个在键 `5`，第 10 个在键 `0`。

**为什么正在跑的时候不亮？** 因为那时你不需要做任何事。灯一亮就必须真有事，
不然你很快就学会不看它了。

**为什么键盘到时间就灭，托盘不灭？** 键盘负责“叫你回来”，所以短促、显眼、会消失；
托盘负责“记账”，所以一直在，回头能查。

## 两种连接方式

插数据线时用有线，拔掉线用 2.4G 无线，程序会自动认，不用你选。

| | 有线 | 2.4G 无线 |
|---|---|---|
| 响应 | 几乎实时 | 你停手 15 秒内跟上 |
| 黄灯 | 呼吸 | 常亮（无线做不到呼吸） |
| 打字时 | 完全不影响 | **可能吞掉你一个字** |
| 摆放 | 被线拴住 | 可以放在旁边当状态牌 |

无线那条“可能吞一个字”不是 bug，是物理限制：每发一次灯，键盘要重建整屏，
那一瞬间按下的键会被吃掉。所以程序**在你打字时一帧都不发**——
这也是为什么无线下灯的内容会比实际状态慢几秒。

连接方式会自动切换：插上线立刻改走有线；拔了线自己回到 2.4G。

## 安装

1. 需要 Python 3.13+（Windows）。
2. 在仓库目录执行下面这行，让它开机自动运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools\install_autostart.ps1
```

不想开机自启，可以手动启动：

```powershell
python tools\run_guard.py
```

3. 托盘出现图标，说明跑起来了。

想撤掉开机自启：

```powershell
powershell -ExecutionPolicy Bypass -File tools\uninstall_autostart.ps1
```

## 托盘菜单

```
☑ 无线键盘也亮灯
  打字时不发帧，避免吞键
────────────
打开日志
打开 OpenCode
────────────
退出
```

**「无线键盘也亮灯」** 是无线模式的总开关：

- 勾上（默认）：拔线之后键盘也会显示灯态
- 取消：拔线之后键盘不参与，程序只提示你用有线；有线照常工作

如果你不想要无线那点“可能吞字”的风险，取消勾选即可，有线一切照旧。

## 灯不亮时，按这个顺序查

1. **键盘灯本身是不是被关了**（键盘自己的背光开关/旋钮）。
2. **官方灯效软件是不是开着**（LEOBOG ONE / OemDrv.exe）。它会独占设备，此时程序会主动避让。
3. **是不是正在跑**——跑的时候本来就不亮。
4. **无线的话，是不是刚打完字**——打字期间不发帧，停手十几秒才跟上。
5. **看日志**（下方路径），搜「未发帧」，它会告诉你原因：
   - `打字中`：你在打字，等着
   - `未到补帧周期`：上一次发帧不到 35 秒
   - `合并窗口`：变化刚发生，1 秒内合并
   - `无线发帧失败`：键盘睡着了，按一下键盘就能叫醒

## 停止

右键托盘图标 → 退出。

退出后键盘不再受控：有线约 1 秒回到键盘自己的灯效；无线会保持最后那一帧一会儿，
然后由键盘自己决定（可能变回自带灯效，也可能熄掉）。

## 日志与设置

都在这个目录：

```
%LOCALAPPDATA%\opencode-keyboard-traffic-light\
├── guard.log      每次运行的日志，自动轮转（1 MB × 3 份）
└── settings.json  托盘开关的记忆（重装/删除都不影响键盘）
```

日志里只有会话编号、项目名和灯态，没有对话内容，也没有密码。

## 支持哪些键盘

| 键盘 | 连接 | 状态 |
|---|---|---|
| LEOBOG Hi86 | 有线 / 2.4G 无线 | 已验证 |
| 新盟 M75V2 | — | 未验证，只探测不驱动 |

换一把键盘、或者换一个 USB 口，都不用改配置——程序每次启动自己去找。

## 开发

想改代码的话：

- 术语表：`CONTEXT.md`
- 决策记录：`docs/adr/`（灯态语义见 0002，无线发送时机见 0007）
- 无线实测数据与踩过的坑：`docs/2.4G-LED-验证记录.md`
- 跑测试：`python -m pytest -q`

主要模块：

| 文件 | 干什么 |
|---|---|
| `core.py` | 纯状态机：事件 → 灯态 / 槽位 / 通知 |
| `keyboard.py` | 有线灯口：状态机 + 20 fps 发帧 |
| `wireless.py` | 2.4G 灯口：只决定「什么时候发」 |
| `dongle.py` | 2.4G 协议 I/O（分包、CRC、ACK） |
| `frame.py` | 灯态 → 520 字节帧（有线） |
| `profiles.py` | 机型档案；未验证机型拒绝写入 |
| `tray.py` | 托盘图标与菜单 |
| `keyboard_hub.py` | 多键盘调度、热插拔、故障隔离 |

排查工具在 `tools/`：`probe_keyboard.py` 看设备、`probe_keystate.py` 看键盘活动、
`wired_walkthrough.py` 在真机上走一遍灯态。
