2.4G 发帧门控

# 发一帧 = 全键盘黑约 1 秒 + 可能丢一次按键
on_state_change:
  mark_dirty()

tick:
  if 距上次按键 < 20 秒:      # 人在打字
    return                    # 灯靠按键自己维持
  if now - last_send < 45 秒:
    return
  if now - last_dirty < 2 秒:   # 去抖合并
    return
  send_frame()
打字期间不发帧，是因为实测每帧必丢一次按键事件（15 帧 15 次）。
