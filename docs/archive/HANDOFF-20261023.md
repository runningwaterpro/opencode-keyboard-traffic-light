## 已定关键决策（别再翻案）

- 重建范围 = 运行中 ∪ 有待处理（permission/form）；不复活历史失败（防常亮红）。
  记忆中会话按 REST 全量列表打补丁（outcome=failed 且未运行 → 红；succeeded/interrupted → 绿）；
  缺席才移除；分页不完整（all_ids=None）则跳过移除。
- 中断：user/superseded → 静默回空闲；shutdown/inactivity → 红；未知 reason → 静默（保守）。
- 等待保底 500ms（WAITING_MIN_VISIBLE_MS）；同会话多个待处理全清才离开等待；瞬间处理也亮满保底。
- 优先级 黄>红>紫>绿；子会话按 parentID 显示时折叠成组；fork 会话（有 fork 无 parentID）按普通会话。
- payload 字段：permission.asked→data.id；permission.replied→data.requestID；form.created→data.form.id / data.form.sessionID；
  form.replied/form.cancelled→data.id。无 requestID 的 replied 兜底清该会话全部权限类待处理。
- M1：键 1 = 全体最高优先级；无会话=灭。dry-run 只写日志、不碰键盘、不发通知。
- 重建 add 例外：新加的只有 running/pending 的会话；纯 idle 历史会话不进场。
