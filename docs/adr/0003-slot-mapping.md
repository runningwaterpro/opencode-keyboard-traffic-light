# ADR-0003：槽位映射——编号绑定会话，只占不重排

**状态**：已接受

## 决策

数字键 1–0 为槽位，一个槽位绑定一个会话：

- 会话收到第一个事件时占用最小空号（1→…→9→0）；已占的号不因后来者重排。
- 空闲会话继续占号；归档/删除即释放。
- 槽位满又来新会话：先淘汰“最久处于空闲”的；没有空闲的淘汰“最早的失败”；连失败也没有（十格全是等待/执行中）就暂不占号，等腾出再补。
- 子会话折叠进父会话，不占号。
- 通知里带该会话的“#编号”。

## 理由

编号是人眼找会话的锚点；重排一次，锚点就丢一次。淘汰顺序即“最不需要被看见的先失去特权”：空闲 > 失败 > 等待/执行中。
