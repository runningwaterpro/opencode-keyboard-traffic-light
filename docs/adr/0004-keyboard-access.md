# ADR-0004：键盘访问策略——仅有线、唯一写者、与 SignalRGB/雷蛇零关联

**状态**：已接受

## 决策

- **仅支持有线**：一帧灯光 520 字节；2.4G 接收器最大特征报告只有 8 字节，物理上发不出去（leobog 实测）。检测到只插了接收器就提示换线，不硬撑。
- **同一时刻唯一写者**（沿用 leobog 红线）：独占打开设备；`OemDrv.exe`（官方程序）在跑就完全不碰设备；只写实时数据对象 `0x08`；发包前四项特征（VID、PID、UsagePage、特征报告长度）全部核对；一次失败即停，不循环重试。
- **与 SignalRGB、雷蛇零关联**：不检测、不联动、不让路。两边同时开着时的写入争抢由用户手动处理（已知并接受）。唯一例外是上面那条对官方程序的避让。

## 理由

键盘有变砖级前科（OpenRGB 曾误伤同控制器的键盘）。HID 通道宁保守勿聪明；SignalRGB 集成没有需求，只有维护负担与风险。
