# ADR-0005：守护用 Python（评估过 Rust）

**状态**：已接受

## 背景

守护要长时间常驻，占用要尽量低。评估过改用 Rust 的选项（本机不装 Rust 工具链，由 CI 编译）。

## 决策

用 **Python**（本机 3.13）写守护。

## 理由

- 负载本质：事件驱动 + 每 50ms 一个 520 字节帧（灯要连续发帧保持）；大头是系统调用，两种语言相同。
- 本机实测：Python 骨架常驻 ≈24 MB；组帧 19 µs → 20fps 下 0.04% 单核。Rust 估计省 ≈20 MB 内存，CPU 同量级。
- 代价对比：不装工具链时，Rust 每轮改动都要过 CI 编译才能测，还要放弃 leobog 的现成代码（组帧等）。省 20 MB 不值。
- 落在“没必要追求极致”的区间；将来真嫌它大，再评估迁移（项目小，重写可控）。
