# 键盘失败后重试，而不是永久停灯

## 背景

旧规则是“一次失败即停该键盘，永不重试”，目的是绝不对错误设备写入。多键盘与热插拔之后，这条规则会让一次瞬时故障（拔线、独占被占、驱动重启）永久废掉一把键盘，用户必须重启守护才能恢复。

## 决策

按失败类型分档：

- 校验不符（VID/PID/usage/报告长度不匹配）：该设备停到拔插，绝不重试——错误设备一个字节都不写。
- 独占打开失败、发帧失败：该设备退避重试 5s / 15s / 60s；连续 3 次仍失败则停到拔插。
- 设备消失（拔线）：不计数，插回即恢复。

每次成功打开都会清零失败计数。故障只影响该设备，其他键盘与托盘不受影响。

## 后果

- 瞬时故障可自愈，不再需要重启守护。
- 对同一路径最多重试 3 次，不会无限刷设备。
- “校验不符”仍是硬红线，安全边界没有放宽。
